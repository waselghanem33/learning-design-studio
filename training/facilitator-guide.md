# Learning Design Studio — Facilitator Guide / دليل المدرب

**Dr. Wasel Ghanem — Birzeit University**

## Workshop / الورشة (120 minutes)

| Time | Activity | Deliverable |
|---|---|---|
| 0–10 | Opening: redesign a lecture | Authentic challenge |
| 10–25 | UCL Learning Designer demonstration | Familiarity with six learning types |
| 25–40 | Write measurable learning outcomes | 2–3 outcomes |
| 40–55 | Match activities to learning types | Activity classification |
| 55–90 | Design lab: before/during/after | Draft module |
| 90–110 | Peer review using weighted rubric | Feedback and revision |
| 110–120 | Reflection and exit ticket | One improvement commitment |

## Facilitation notes

Ask participants to select a real module from their teaching. Use the discipline examples as scaffolds, not as prescriptive lesson plans. In the design lab, ask them to specify student instructions, teacher presence, group size, resources, formative assessment and timing. Compare the activity-time chart with the intended outcomes. Participants then complete the progress-dashboard challenges and peer-review one another's designs.

## ملاحظات للمدرب

اطلب من كل مشارك اختيار وحدة حقيقية من مساقه. استخدم أمثلة القانون والطب والصيدلة والأعمال والتربية والهندسة والعلوم الاجتماعية كنقاط انطلاق. في مختبر التصميم، ركّز على تعليمات الطلبة ودور المدرس وحجم المجموعة والموارد والتقييم التكويني والوقت. اختم بمراجعة الأقران والتأمل.
